# Web Security

The largest topic in the archive: seven SSRF scenarios, twenty-four SQL/NoSQL injection labs, thirteen access-control labs, IAM with Keycloak, and a five-part DevSecOps track.

**Level:** 4th year — semester 2  
**Tools:** Python, Flask, Docker, Burp Suite, SQLMap, Keycloak, LDAP, GitLab CI

> Complete and self-contained; all secrets have been redacted.
