# Cybersecurity with Zeek

Network-security monitoring with Zeek: protocol logs, detection scripting and traffic-analysis labs.

**Level:** 4th year — semester 2  
**Tools:** Zeek, Docker, DVWA

> Labs 2, 5 and 6 have real artefacts; lab 3 is sheet-only.
