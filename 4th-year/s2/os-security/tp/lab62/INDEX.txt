┌─ 🔄 WORKFLOW NODES (6 Total) ─────────────────────────────────────────────────┐
│                                                                                │
│  1. Schedule Trigger (Cron)
│     └─ Runs: Every 1 minute
│
│  2. Execute Command - Hash File
│     └─ Command: sha256sum /files/fim_target.txt | awk '{print $1}'
│
│  3. Function - Compare Hash
│     └─ Compares current hash with stored hash
│     └─ Sets: alert = true/false
│
│  4. IF Condition
│     └─ Checks: alert == true
│
│  5. Execute Command - Write Alert (True Branch)
│     └─ Logs: [TIMESTAMP] ALERT: ... old=... new=...
│
│  6. No Alert (False Branch)
│     └─ No action if file unchanged
