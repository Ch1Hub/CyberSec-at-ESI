# IoT Security

Embedded-programming practicals on ESP8266 and Wemos boards, from GPIO to an HTTP server and MQTT telemetry.

**Level:** 4th year — semester 2  
**Tools:** Arduino C++, ESP8266, MQTT

> Six practicals; lab 6 is a third-party tutorial used as-is.

## Labs

| Lab | What it covers | Status |
| --- | --- | --- |
| [Lab 1 — ESP8266 hello world](lab1/) | Blinking LED and serial output on an ESP8266 board. | 🟦 Code archived |
| [Lab 2 — Analog sensor acquisition](lab2/) | Reading an analog sensor over the ESP8266 ADC and printing values to the serial monitor. | 🟦 Code archived |
| [Lab 3 — Keypad input](lab3/) | 4x3 keypad handling with an ESP8266 and the Keypad library. | 🟦 Code archived |
| [Lab 4 — ESP8266 web server](lab4/) | HTTP server on the ESP8266 serving buttons that switch an LED on and off. | ✅ Lab work archived |
| [Lab 5 — MQTT with a Wemos board](lab5/) | DHT sensor publishing telemetry to a public MQTT broker, with the lab sheet and a transcribed copy. | ✅ Lab work archived |
| [Lab 6 — IoT stack tutorial](lab6/) | Docker-based IoT stack tutorial (InfluxDB, Telegraf, Grafana, MQTT) used for the lab. | 🟨 Partial archive |
