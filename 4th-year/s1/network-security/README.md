# Network Security

Broad network-security course: Nmap and service discovery, ACLs, IDS design in Python, packet analysis and a full XGBoost intrusion-detection project.

**Level:** 4th year — semester 1  
**Tools:** Python, Scapy, XGBoost, Nmap, Nikto, tcpdump, Wireshark

> The IDS prototypes in this topic are the most substantial deliverables.

## Labs

| Lab | What it covers | Status |
| --- | --- | --- |
| [l-ids — Hybrid rule and ML IDS](l-ids/) | Second iteration of the IDS with a rule engine alongside the ML detector, alert logging and PCAP replay support. | 🟦 Code archived |
| [lids — XGBoost network IDS](lids/) | Flow-based intrusion-detection prototype: Scapy capture, feature extraction and an XGBoost classifier for benign, DDoS, port-scan and brute-force traffic. | 🟦 Code archived |
| [TD1 — Nmap practice](td1/) | Nmap tutorial exercises and scan output. | 🟦 Code archived |
| [TP1–TP9 lab sheets](tp/) | Assignment sheets and a consolidated lab guide for the network-security practicals. | 📄 Assignment sheet only |
| [TP3 — ACL project](tp3/) | Network ACL practical work with packet-filter configurations and a small project directory. | 🟦 Code archived |
| [TP5 — Service scanning evidence](tp5/) | Nmap service/version scans and Nikto web-server findings collected during the lab. | 🟦 Code archived |
